# Essential Eight and ISM mappings

This directory stores structured machine-readable mappings between the [ASD Essential Eight Maturity Model](https://www.cyber.gov.au/resources-business-and-government/essential-cyber-security/essential-eight/essential-eight-maturity-model), the [ASD Information Security Manual (ISM)](https://www.cyber.gov.au/resources-business-and-government/essential-cyber-security/ism) and Microsoft Sentinel content in this repository.

## Files

- `e8-requirements.yaml` - Essential Eight requirements across Maturity Levels 1 to 3 with observability status and Microsoft telemetry tables
- `ism.csv` - Mapping of analytics rules, hunting queries and workbook tiles to ISM control identifiers
