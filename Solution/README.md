# Solution content

This directory follows the [Microsoft Sentinel Content hub solution layout](https://learn.microsoft.com/en-us/azure/sentinel/sentinel-solutions).

## Subdirectories

- `Data/` - Content hub solution data definition (`Solution_EssentialEight.json`) used for packaging
- `Analytic Rules/` - Scheduled Microsoft Sentinel analytics rule templates in YAML format
- `Hunting Queries/` - Microsoft Sentinel hunting queries in YAML format for assessment evidence collection
- `Workbooks/` - Azure Monitor and Microsoft Sentinel workbook JSON templates
- `Package/` - Compiled Azure Resource Manager templates (`mainTemplate.json` and `createUiDefinition.json`)
